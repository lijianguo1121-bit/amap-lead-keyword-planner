# 调研与分级规则

## 1. 先画两条客户链

- **直接价值链**：谁有明确问题、谁能使用产品、谁有预算、谁持续付费。
- **渠道价值链**：谁已经拥有这批客户、谁能转售/贴牌/集成、谁能从持续消费中获益。

同时拥有直接价值和渠道价值的行业通常进入 `priority_1`。

## 2. 三级优先级

### priority_1：高匹配、优先开发

满足多项：需求直接、客户池现成、付费能力强、可自用兼代理、交付简单、存在持续充值或复购。广告/招商产品通常优先考虑广告、营销、传媒、网络推广、招商服务和企业服务商。

### priority_2：明确的终端应用行业

产品能直接解决其获客或经营问题，但未必适合发展渠道。本地高客单、高毛利、依赖线索或有地域定向需求的行业通常归入此级。

### priority_3：潜在或间接机会

有客户资源但需求不直接、预算偏低、决策周期长、合规约束较多，或仅部分企业适用。保留可检索的具体行业词，不用“其他企业”凑数。

## 3. 地图可检索性测试

逐条自问：“把这个词输入高德地图，是否可能返回一批同类实体公司或门店？”

- 通过：广告公司、会展服务、财税服务、汽车 4S 店。
- 不通过：数字化转型、私域流量、降本增效、创业者、高净值人群。
- 将抽象词落到实体：如“私域代运营需求”改为“新媒体公司”或“电商代运营”。

## 4. 市场规模与趋势

1. 搜索当前年份及最近 1–2 年的数据，优先官方统计、行业协会和权威研究。
2. 区分全行业规模、线上细分规模和可服务市场，不把大盘直接当成产品可获得市场。
3. 数字口径不一致时采用更保守、定义更清楚的一项；无法可靠核实时写“规模较大”“区域分散市场”等定性表述。
4. 趋势要反映该关键词对应行业，而不是照搬产品所属赛道。
5. 只使用四个趋势前缀；样本中的“温和下行”等其他枚举统一归并为“下行”或更有依据的“结构性分化”。
6. 不为显得专业而虚构 CAGR、市场规模、年份或预测。

## 5. 最终检查

- 是否既有渠道词又有终端行业词，而非只列产品同行。
- 每条 `logic` 是否体现该行业与输入业务的独特关系。
- 是否存在抽象词、重复词、地图难检索词。
- 是否把未经核实的市场数字写成事实。
- 是否符合严格 JSON 和默认数量要求。
