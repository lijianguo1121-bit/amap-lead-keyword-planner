# Excel 交付契约（基于 v1.2.0 Schema）

## 最终工作簿

默认交付一个 `.xlsx`，包含以下工作表：

| 工作表 | 内容 |
|---|---|
| `business_summary` | 业务摘要、三级关键词数量、趋势计分参考 |
| `priority_1` | 16 条一级优先关键词 |
| `priority_2` | 20 条二级优先关键词 |
| `priority_3` | 20 条三级优先关键词 |
| `资料来源` | 使用外部资料时必需；记录来源名称、URL 和用途 |

用户明确要求其他数量时按用户要求，不擅自补足 56 条。

三个优先级工作表的表头严格为：

```text
keyword | logic | market_size | trend
```

不要增加优先级、评分或来源列；优先级由工作表名称表达，来源统一放入 `资料来源` 页。

## 中间 JSON

```json
{
  "business_summary": "一段话概括产品、客户、渠道与持续收益模式",
  "priority_1": [
    {
      "keyword": "广告公司",
      "logic": "本身经营广告业务，既可为现有客户补充投放工具，也可发展为渠道代理",
      "market_size": "有可靠来源时写规模和年份；否则写定性规模",
      "trend": "结构性分化，传统业务承压，数字化需求增长"
    }
  ],
  "priority_2": [],
  "priority_3": []
}
```

中间 JSON 顶层只保留 `business_summary`、`priority_1`、`priority_2`、`priority_3`，关键词对象只保留四个规定字段。

## 字段约束

| 字段 | 约束 |
|---|---|
| `business_summary` | 一个非空字符串；概括业务，不写未提供的价格、效果或资质 |
| `keyword` | 非空地图检索词；全局不重复 |
| `logic` | 非空匹配理由；尽量体现自用、代理或渠道价值 |
| `market_size` | 非空规模描述；可靠数字必须带年份或口径，不确定时定性 |
| `trend` | 以四类趋势之一开头，可追加简短原因 |

趋势前缀及外部程序可使用的建议分值：

- `上涨`：+2
- `温和上涨`：+1
- `结构性分化`：0
- `下行`：-2

分值仅供后续程序计算，不写入默认 JSON 或关键词工作表。

## 来源文件

`--sources` 接收 JSON 数组，每项包含：

```json
{
  "source_name": "来源名称",
  "source_url": "https://example.com/source",
  "note": "用于哪些规模或趋势判断"
}
```

使用网络、数据库或外部报告时必须提供来源；用户提供的业务资料无需虚构 URL。

## 排版与验收

- 摘要页突出业务摘要和各优先级数量。
- 关键词页冻结首行、启用筛选，长文本自动换行。
- 建议列宽：`keyword` 20、`logic` 66、`market_size` 42、`trend` 42。
- 导出后重新打开工作簿，核对表名、表头和行数，并通过 Excel 文件验证。
